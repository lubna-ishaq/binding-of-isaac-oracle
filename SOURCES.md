# Sources

## Item Data

- Source page: https://bindingofisaacrebirth.wiki.gg/wiki/Items
- Generated by `scraper/scrape_items.py` into `frontend/src/data/items.generated.json`.
- Wiki content is licensed under CC BY-SA 4.0 unless noted otherwise, so the generated item data uses the same license.
- Only Repentance+ values are kept.
- Item icons are not in this repo. The app loads them from the wiki and they belong to their owners.

## Heart Assets

- Source page: https://bindingofisaacrebirth.fandom.com/wiki/Hearts
- Retrieval date: generated by `scraper/scrape_heart_images.py` and recorded in the scraper output.
- The Fandom page states that community content is available under CC BY-NC-SA unless otherwise noted.
- Individual media files may have separate attribution or licensing information. Each asset must be reviewed with its exact source URL before redistribution.
- Isaac Oracle is a fan-made project and is not affiliated with the game developer or publisher.

The exact source image URL and local filename for each discovered asset are recorded in `scraper/output/hearts.generated.json`. The scraper does not invent or download an asset when its source image was not found.
