Heart Container Kit

Pixel-Herzen für dein React-Projekt — als SVG-Komponente, die sich per Prop füllen, umfärben und animieren lässt, und als PNG-Set in vier Auflösungen. Jeder Typ hat nur die Zustände, die es wirklich gibt: ein leeres Seelenherz zeichnet die Komponente gar nicht erst.

01

Alle Typen

Jede Kachel zeigt genau die Zustände, die der Typ hat. Ein Klick schaltet durch. Halbe Herzen trennen bei Spalte 7 des Rasters — harte Kante, kein Verlauf.

Lebensleiste

hp zählt in halben Herzen, genau wie im Spiel: aus hp=5 werden zwei volle und ein halbes. Klick auf ein Herz setzt die Leiste auf diesen Stand.

03

Benutzung

Eine Datei, keine Abhängigkeiten außer React — die Pixeldaten stecken lauflängen­kodiert in der Komponente.

// PixelHeart.jsx ins Projekt kopieren
import PixelHeart, { HeartRow, STATES_BY_TYPE } from "./PixelHeart";

// fester Zustand
<PixelHeart type="red" state="half" size={48} />

// Anteil 0..1 -- wird auf einen Zustand gerundet, den der Typ hat
<PixelHeart type="soul" ratio={hp / maxHp} />

// klickbar: schaltet nur durch die gueltigen Zustaende
<PixelHeart type="black" interactive onChange={s => setState(s)} />

// Palette punktuell ueberschreiben
<PixelHeart type="red" colors={{ base: "#ff2e88", hi: "#ffa8cf" }} />

// Gold ist ein Rahmen -- innen transparent, also drueberlegen
<div style={{ position: "relative" }}>
  <PixelHeart type="red" state="full" size={48} />
  <PixelHeart type="gold" size={48} style={{ position: "absolute", inset: 0 }} />
</div>

// ganze Leiste, hp in halben Herzen
<HeartRow hp={5} max={12} type="red" size={40} />

Im Paket

Die PNGs liegen in vier Auflösungen bereit, falls du lieber Bilddateien einbindest. Beim Skalieren image-rendering: pixelated setzen — sonst verwäscht der Browser die Kanten. Die Wrapper tun das schon.

react/PixelHeart.jsx   SVG-Komponente + HeartRow
react/SpriteHeart.jsx   PNG- und Spritesheet-Wrapper

hearts-spritesheet.png   192×640, Kachel 64×64

heart-data.json   Geometrie + Paletten für Canvas, WebGL, Unity …
